# SINCRIA - Handheld Games firmware

Arduino Nano ATmega328P, 16 MHz; LedControl 1.0.6. Firmware dated 28 October 2026.

Open `SINCRIA_Scansione_Righe.ino` in Arduino IDE. Select Arduino Nano and the processor/bootloader fitted to the board.
